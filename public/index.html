Авторизация

Нажмите «Подключить Atlassian». TeamWork откроет официальный экран Atlassian OAuth 2.1 в браузере и вернёт вас в приложение после подтверждения доступа.

Client ID, Client Secret и API token не требуются. Используется только встроенный Jira MCP с официальным Atlassian Rovo MCP в качестве защищённого upstream.
